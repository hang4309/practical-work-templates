# 交表前的六个检查｜开始使用

这是给行政、运营新人和培训讲师的离线练习包。它把 CSV/Excel 交表前最容易被忽略的六类问题做成了确定答案的小练习；所有业务名称、编号和金额均为本包合成数据。

## 文件与顺序

1. 打开 `index.html`，按页面顺序完成六题。题目页已嵌入全部作答数据，答案默认不显示；可用浏览器打印为纸本或另存 PDF。
2. `samples` 是可选附件：适合想练习打开 CSV 原文或导入表格软件的学员。完成本练习不依赖 Excel，也不必打开附件；不要直接修改原文件。
3. 讲师完成讲解后，再打开 `instructor.html` 核对。该页含答案、理由和 15–25 分钟课堂安排。

## 练习范围

本包训练的是提交前的人工判断：确认分隔符、表头、合并键、空值、金额小数和 Excel 日期序号。它不是自动导入器、会计意见或真实业务数据清洗服务。遇到真实数据时，应按本单位数据规范和负责人意见处理。

## 建议课堂用时

建议使用 20–25 分钟：先让学员两人一组阅读题内数据，再逐题解释为什么“看起来能打开”仍不代表“可以交”。若只有 15 分钟，可跳过可选的真实脱敏表迁移活动，保留六题快速揭晓。

## 隐私与保存

页面没有联网、没有上传功能，也不会自动保存答案。若在纸本或浏览器中记录答案，请自行按单位要求保存或销毁。
