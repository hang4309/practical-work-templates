# Provenance and validation

These six HTML forms and four workbooks were newly edited from workflow concepts and sample structures in existing local assets, identified as 0118, 0120, 0124, 0134, 1605, 2509, 3005, 3157, 3352 and 3363. The source programs and private asset collection are not included.

Some starting values and category concepts came from fixtures described by their source documentation as synthetic; they are not customer case studies. New workbook examples are explicitly illustrative. Original notice text is preserved in SOURCE_NOTICES.md.

The HTML clear/save/print implementation was newly written. A saved copy stores current input, textarea, select and checkbox state. Two representative forms were tested in Chrome by saving their generated HTML and opening it again; six forms received structural checks. The mobile page body was checked at 390px; wider tables scroll within their containers. Print media hides the toolbar.

Four XLSX workbooks were reopened and all nonempty cells and metadata inspected. They contain no formulas, macros or external workbook links. This does not establish identical rendering in every spreadsheet application.

These are human intake/checklist templates, not direct input contracts for the original programs. They do not perform automated OCR, image editing, video production, question authoring, external account integration or inventory correction. Any actual processing service requires its own input and delivery scope.

The public package includes only the ten templates and these new explanatory files/notices. Browser profiles, QA copies, internal raw samples and original local absolute paths are excluded.
