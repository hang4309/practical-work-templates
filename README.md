# 日常工作表单 / Practical Work Templates

Chinese files for everyday work: six offline HTML forms, four XLSX workbooks, and an office data-check training pack. The materials are free and editable.

## 怎么使用

打开 index.html 选择场景。HTML表单点击“清空开始填写”，填好后点“保存填好副本 HTML”或打印；刷新页面不代表已经保存。工作簿在支持XLSX的软件中打开，先读说明页，再填空白页。所有示例均标记为合成例子。

六份表单：资料来源交接、商品资料清洗、图片素材检查、纪实视频素材交接、培训测验组卷、客户工作流交接。

四份工作簿：两表对账、布草收发、庭院除草、婚礼拍摄。

HTML不上传填写内容、不连接外部服务。XLSX没有宏、公式或外部工作簿连接。本轮在Chrome检查了两份HTML的保存后重开，其他表单做了结构一致性检查；四份XLSX均重开并检查内容。

## 修改与反馈

可以在自己的副本上修改文字、字段和流程。反馈时描述缺什么字段、哪个步骤不清楚，必要时附纯合成例子；公开问题区不要上传真实客户信息或内部业务文件。基础文件可以免费使用；针对具体工作流程的适配另列范围，本仓库不自动接受订单。

来源、改编及验证范围见 PROVENANCE.md，源材料通知见 SOURCE_NOTICES.md。当前没有使用量、节省时长或成交承诺。
