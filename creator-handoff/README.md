# 短视频交付包：让接收方知道该看哪一版

给独立剪辑师、内容工作室和课程助教使用。免费、可修改，无需开通服务。里面已经填好一份真实可播放的36秒交付示例，并附两份可复制的交付/反馈模板。

直接打开 `index.html`，看视频和六段时间线；再读 `检查流程.md`。示例片是有字、无声卡片，不需要找不存在的配音文件。不是客户委托案例。

开始自己的项目：复制templates中的两份文字模板；填上实际文件与版本，列清楚字幕、封面和项目文件要求；参照example里的素材记录和变更记录填写。不会编程也可以完成这一步。

文件核对是可选项。需要时使用Python 3.10或更新版本运行 `python check_delivery.py example/manifest.json`，无需安装第三方库。把新项目改成相同清单结构前，先读检查范围；程序不会自动批准交付或发布内容。

文件：
- index.html：可播放的说明页。
- example/：原视频、六张卡片、封面、六条SRT摘要、时间线、字幕规则、素材记录、变更记录与哈希清单。
- templates/：可复制的交付说明和修改意见模板。
- check_delivery.py：只读文件清单和严格SRT的可选核对器。
- PROVENANCE.md / SOURCE_NOTICES.md / LICENSE：改编来源和许可。

这套配套材料能统一交付方式。实际剪辑、配音、翻译、素材授权确认和针对客户的修改仍要按约定完成；本仓库没有自动接单或价格承诺。所有示例数据为合成数据。
